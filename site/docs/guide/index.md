# 使用指南

## 快速开始

1. 勾选左侧「扫描分区」中要扫描的本地磁盘分区。
2. 在「参数配置」中选择扫描类型，按需调整阈值 / 关键字 / 维度。
3. 点击「▶ 开始扫描」，即刻开启极速并发检索。

扫描期间右侧实时显示进度与当前路径；底部状态卡片显示文件数 / 目录数 / 耗时 / 状态。扫描完成后呈现「检索详情清单」。

## 扫描模式

通过顶部「扫描类型」下拉切换预设，不同预设显示不同的条件控件：

### 🔍 大文件

找出占用空间最大的文件。配置「大小阈值」（滑块，单位 MB）筛选，结果按大小降序。可勾选「显示全部结果」或限制 Top N。

### 📄 空文件

检索体积为 0 字节的空文件，显示全部。

### 📁 空目录

检索不含任何子项的真空目录，按路径排序，显示全部。零额外系统调用，速度与遍历持平。

### 🗂 搜文件

按文件名匹配（「精确匹配」复选框切换精确 / 包含）。结果默认按大小降序；可限制 Top N 或显示全部。

### 📂 搜目录

按目录名匹配。可配置：

- **统计维度**：按大小 / 按文件数 / 两者都显示。
- **排序键**（维度选「两者」时可选）：按大小 / 按文件数。

::: warning 目录聚合的呈现方式
目录聚合查询的结果会在**该 root 扫描结束后批量出现**（聚合需要完整子树统计后才能给出目录总量）。进度条仍实时显示文件/目录计数与当前路径，属正常行为。
:::

## 结果操作（复制 / 导出 / 定位）

检索详情清单的每一行，以及结果区顶部工具栏提供以下操作：

| 操作 | 入口 | 说明 |
| --- | --- | --- |
| 📂 定位 | 每行操作列 | 在系统文件管理器（Finder / 资源管理器）中定位并选中该文件/目录。 |
| 📋 复制（单行） | 每行操作列 | 复制该行完整路径到剪贴板。 |
| 📋 复制全部 | 结果区工具栏 | 把所有结果路径用换行拼接后复制到剪贴板。 |
| ⬇ 下载TXT | 结果区工具栏 | 把结果清单导出为 TXT，保存到系统下载目录，并自动在文件管理器中定位。 |

导出的 TXT 为 Tab 分隔（排名 / 大小 / [文件数] / 路径），可直接粘贴进 Excel 等表格软件。

::: tip 扫描中也可操作
复制 / 导出基于当前已收到的结果。扫描进行中（结果仍在累积时）即可复制或导出当前部分。
:::
